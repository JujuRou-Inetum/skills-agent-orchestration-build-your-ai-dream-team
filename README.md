## Project Pulse

Project Pulse is the responsive project portfolio dashboard built during this exercise. It displays project status, priority, ownership, recent activity, search, filtering, and sorting controls.

To run the dashboard locally:

```bash
cd app
python3 -m http.server 5500
```

Then open `http://localhost:5500` in a browser.
